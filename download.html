VIDLOCK-source-latest.zip 다운로드

포함: vidlock-desktop, vidlock-participant, landing, HANDOFF 문서, 실행 배치 파일 · node_modules 제외 (압축 해제 후 npm install 필요)

위 버튼이 안 되면 백업 링크: 직접 다운로드 (GitHub)

다른 AI에게 줄 때 (복사용)

  1. 위 ZIP을 다운로드해 압축 해제
  2. 폴더를 Cursor/VS Code에서 열기
  3. HANDOFF.md를 먼저 읽게 하기
  4. 호스트: cd vidlock-desktop && npm install && npm start
  5. 참가자: cd vidlock-participant && npm install && npm start

ZIP 안 구성

  • vidlock-desktop/ — 호스트(관리자) v1.6.1
  • vidlock-participant/ — 참가자 v1.0.0
  • landing/ — 소개·설명서·관리자 연습 페이지
  • HANDOFF.md — 버그·테스트·IPC 채널 정리
  • 시작_호스트.bat / 시작_참가자.bat
