01 연습 환경 준비 (PC에서 1회)

웹 링크만으로는 앱이 실행되지 않습니다. 아래 순서로 로컬 PC에서 앱을 켠 뒤, 이 페이지의 체크리스트를 보며 연습하세요.

Node.js 18+ 설치 → VIDLOCK 폴더 열기

# 호스트(관리자) 앱
cd vidlock-desktop
npm install
npm start

# 참가자 앱 (새 터미널)
cd vidlock-participant
npm install
npm start

Windows: 시작_호스트.bat / 시작_참가자.bat 더블클릭으로도 실행 가능
