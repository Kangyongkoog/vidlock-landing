1. 앱이란 / 역할 구분

VIDLOCK은 Zoom 화상회의 중 화면 녹화·캡처·외부 촬영 시도를 줄이기 위한 데스크톱 보안 앱입니다.

앱대상역할
vidlock-desktop호스트·강사·관리자회의 관리, 보호 모니터링, 설정
vidlock-participant참가자·수강생링크로 보호 참가, 녹화·촬영 차단
참가자 앱은 무료 배포를 전제로 설계되어 있습니다. 유료는 호스트 라이선스 중심입니다.

2. 설치와 실행

준비물

  • Windows PC (주력)
  • Node.js 18 이상
  • VIDLOCK 소스 폴더 (vidlock-desktop, vidlock-participant)

실행 방법 A — 배치 파일

  1. VIDLOCK 폴더에서 시작_호스트.bat 더블클릭 → 관리자 앱
  2. 시작_참가자.bat 더블클릭 → 참가자 앱

실행 방법 B — 명령어

# 호스트
cd vidlock-desktop
npm install
npm start

# 참가자 (새 터미널)
cd vidlock-participant
npm install
npm start
웹 랜딩 페이지만으로는 앱이 실행되지 않습니다. 각 PC에서 앱을 설치·실행해야 보호가 적용됩니다.

3. Zoom 회의 보호 참가

참가자 앱

  1. 💬 회의 참가 탭으로 이동
  2. Zoom 초대 링크 또는 회의 ID 붙여넣기
    예: https://us06web.zoom.us/j/123...?pwd=...
  3. 🔒 보호 참가 클릭

호스트 앱

  1. Zoom 패널에서 회의 ID/URL 입력 (비밀번호 칸 사용 가능)
  2. 🔒 보호 참가 또는 새 회의/로그인 버튼 사용
초대 링크에 pwd=가 있으면 비밀번호를 따로 입력하지 않아도 됩니다. 앱이 웹 참가(wc/join) 주소로 변환해 보호 창에서 엽니다.

4. 녹화·캡처 차단

  • OS setContentProtection — 녹화 시 해당 창이 검게 나오도록 OS 레벨 보호
  • 감지 OBS, 반디캠 등 녹화 프로세스 주기 감시 → 블랙아웃·경고
  • 경고 PrintScreen 등 캡처 시도 시 위반 경고 표시

보호가 켜진 상태에서 Zoom을 VIDLOCK 앱 안에서 열어야 효과가 큽니다. 일반 브라우저만으로 열면 보호가 약해질 수 있습니다.

5. AI 폰·카메라 촬영 감지

PC 웹캠으로 주변을 보고, AI가 휴대폰·카메라를 감지하면 화면을 잠급니다. (Manus/기존 구현 포함)

켜는 방법

  1. 📷 카메라 감지 탭 이동
  2. 웹캠 권한 허용
  3. 감지 시작 클릭
  4. 민감도·간격은 설정에서 조절

동작

  • 연속 감지 시 확정 → 블랙아웃
  • 위반 경고 + 포렌식 워터마크에 기록
  • 장치를 치우면 자동 복구
한계: 웹캠 시야 밖(모니터 뒤·옆) 촬영, 고의로 가린 촬영은 놓칠 수 있습니다. “100% 차단”이 아니라 감지·차단·경고·추적으로 이해해 주세요.

6. 포렌식 워터마크

  1. 🔒 보호 / 워터마크 설정으로 이동
  2. 참가자 이름 입력
  3. 투명도 조절 후 활성화

화면에 이름·시간·IP·경고 문구가 반투명으로 표시되어, 촬영·녹화본에 함께 남습니다. Zoom 계정 워터마크 설정 가이드는 호스트 앱에도 안내되어 있습니다.

7. 학교·시험 모드 로드맵

지금은 Zoom 회의·강의 유출 방지가 중심입니다. 학교 시험용은 아래를 추가 개발할 예정입니다.

목표현재시험 모드(예정)
화면 녹화 차단✅✅ 유지
폰으로 문제 촬영△ 웹캠 시야 내상시 감지 + 로그 강화
다른 탭·AI 검색△ 일부전체화면 잠금·다른 앱 차단
다른 기기 AI 풀이❌감독·2카메라 등 별도 정책
펀딩·학교 도입 시 문구는 “컨닝 완전 차단”보다 “화면 유출·폰 촬영 억제 + 시험 보조 감독”이 정확합니다.

8. 자주 묻는 질문

Q. 다른 사람 PC에서도 링크로 앱이 열리나요?

소개·설명서 페이지는 링크로 열립니다. 앱 자체는 그 PC에 설치·실행해야 합니다.

Q. 보호 참가를 눌렀는데 회의가 안 열려요.

참가자 앱 IPC 채널명(open-meeting-inapp)이 맞는지, 링크 형식이 Zoom인지 확인하세요. 관리자 버그 연습 페이지 체크리스트를 따라 주세요.

Q. Mac에서도 되나요?

코드상 일부 지원이 있으나, 주력 테스트·배포는 Windows입니다. Mac은 로드맵에 있습니다.

Q. 문의는?

사전 구독·도입 문의는 소개 페이지 신청 폼 또는 와풀 AI 교육연구소로 연락해 주세요.
